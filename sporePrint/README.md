## Latent NFTs

Not blockchain NFTs. *Latent* = hidden, potential, unrealized.

Every game in the Steam library has latent value:
- GPU behavior profiles (how does this game use the hardware?)
- Thermal signatures (what does a 4-hour Crimson Desert session look like?)
- Shader complexity maps (which scenes max the GPU? which are idle?)
- Play patterns (where does Kevin spend time? what does A-Life emergent AI look like in telemetry?)

These are "tokens" of knowledge the organism mints by playing. Not on a chain — in the organism.
